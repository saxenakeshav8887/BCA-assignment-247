Terminal navigation practice sheet:→

•pwd-shows current directory 
•ls-list files and folders
•mkdir website- creates a folder 
•cd website: opens a folder 
•cd..: Goes back to the parent folder
•ls-R: Lists files recursively 
•clear: clears the terminal screen 
•touch index.html: Creates a file(Linux/macOS)
•mv index.html home.html: Renames a file
•rm home.html: Deletes a file
